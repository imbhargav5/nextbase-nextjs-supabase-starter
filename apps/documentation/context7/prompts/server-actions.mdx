## Public anon action (careful)

<Prompt description="Copy — rate-limited or newsletter-style public action" actions={["copy", "cursor"]}>
Add a public server action for: [e.g. waitlist signup, contact form].

Security requirements:
- actionClient with strict Zod limits (length, email format, honeypot field optional).
- Context7 query-docs for Next.js Server Actions security (treat like public API).
- No user PII in logs; insert via Supabase with RLS allowing anon insert only on intended table/policy.
- Consider duplicate submission handling and user-facing error messages.

Explain why this should NOT use authActionClient.
</Prompt>
