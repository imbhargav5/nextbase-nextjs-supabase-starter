NextBase enables **`cacheComponents: true`** in `apps/web/next.config.ts`. Route segments are static by default; personalized data stays dynamic inside Suspense boundaries.

## Patterns

- Mark stable UI (shells, marketing blocks) with `"use cache"` where appropriate.
- Leave user-specific fetches uncached and wrap them in Suspense.
- Invalidate from server actions with `revalidatePath()` after mutations.
