## Meta prompts (any task)

<Prompt description="Copy — plan a feature before writing code" actions={["copy", "agent"]}>
I want to implement: [DESCRIBE FEATURE].

Before coding in NextBase Starter:
1. Read AGENTS.md and list which apps/ folders will change (apps/web, apps/database, packages).
2. Use Context7 for any external API I mention (resolve-library-id, then query-docs per topic).
3. Propose a short plan: routes, data layer (anon/auth/user in src/data), RLS if Postgres changes, and tests.
4. Call out risks (auth bypass, missing RLS, cache staleness, hydration).

Wait for my approval on the plan, then implement with minimal diff and match existing conventions.
</Prompt>

<Prompt description="Copy — debug with docs, not guesses" actions={["copy", "agent"]}>
Something is broken: [SYMPTOM]. URL or route: [PATH]. Error message: [PASTE].

Investigate in NextBase Starter:
1. Reproduce from code paths (middleware, RSC, server action, or Supabase client).
2. Use Context7 query-docs for the relevant library (Next.js, @supabase/ssr, etc.) for the exact API we use.
3. Check env (root .env.local, NEXT_PUBLIC_SITE_URL, Supabase URL/keys after pnpm supabase:sync-env).
4. Propose the smallest fix and add or update a test if the bug is regressable.

Do not change unrelated files.
</Prompt>

<Prompt description="Copy — review a PR for security on this stack" actions={["copy", "agent"]}>
Review my uncommitted changes (or branch diff) for NextBase Starter with a security lens:

- Server actions: authActionClient or explicit session checks; Zod validation on input.
- Database: RLS on new tables; no trusting client-sent user IDs without auth.uid() checks.
- Auth: getUser() in middleware; no secrets in client bundles.
- Context7: if I used a new library, verify APIs against query-docs output.

List findings by severity with file paths and suggested fixes.
</Prompt>

<Prompt description="Copy — onboard a new teammate with Context7" actions={["copy", "agent"]}>
Explain how a new developer should work in NextBase Starter in under 5 minutes:

- Monorepo layout (apps/web, apps/database)
- Setup: ./setup.sh or manual steps from docs
- Where auth, data, and safe actions live
- How to use Context7 for coding agents for Next.js and Supabase questions
- One example prompt from the docs prompt library for adding a CRUD feature

Link to repo paths, not vague names.
</Prompt>
