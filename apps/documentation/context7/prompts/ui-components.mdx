UI lives in `apps/web/src/components/` and shadcn primitives in `src/components/ui/`. Use Context7 for shadcn/ui and Tailwind when adding new patterns.

## Add a shadcn component

<Prompt description="Copy — install and use a registry component" actions={["copy", "cursor"]}>
Add shadcn component [NAME] for [USE CASE] on [PAGE/FEATURE].

Steps:
1. Context7 query-docs for shadcn/ui CLI add command and component API for [NAME].
2. Use existing apps/web components.json and path aliases (@/components/ui).
3. Style with Tailwind v4 tokens from src/styles/globals.css; dark-first like the rest of the app.
4. Prefer Server Component wrapper + small Client island for interactivity.

Do not duplicate components that already exist under src/components/ui/.
</Prompt>
